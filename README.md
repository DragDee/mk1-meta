# MK1 META

Independent Mortal Kombat 1 ranked-set analytics: fighter cards, actual and weighted win rates, matchups and Kameo popularity.

This repository contains only the static website, official artwork and fonts with source credits, and anonymous aggregate statistics. Collection tools, game/account authentication, raw records, databases, logs and player identifiers are not included.

Statistics describe a collected sample, not all of Kombat League. Data refreshes when a new aggregate snapshot is published. See the methodology panel on the website for details.
